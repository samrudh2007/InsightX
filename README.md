# InsightX — AI-Powered Customer Intelligence Platform

InsightX is a project focused on analysing customer feedback and extracting meaningful insights using data analysis, machine learning, and artificial intelligence.

## Problem Statement

Businesses receive large amounts of customer feedback through reviews, surveys, and support channels.

Manually analysing this feedback makes it difficult to identify customer dissatisfaction, recurring complaints, and areas that need improvement.

InsightX aims to simplify this process through automated analysis.

## Project Goals

- Analyse customer feedback.
- Identify customer satisfaction patterns.
- Detect recurring complaints.
- Perform sentiment analysis using NLP.
- Generate actionable business insights.
- Build an AI-powered customer intelligence system.

## Technology Stack

- Python
- Pandas
- Machine Learning (planned)
- Natural Language Processing (planned)
- Large Language Models (planned)
- RAG (planned)

## Current Features

- Load customer feedback from CSV files.
- Display dataset information.
- Identify missing values.
- Calculate average customer ratings.

## How to Run

1. Clone the repository.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python src/main.py
```
